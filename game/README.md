# Game

A holding area for early design notes on the **potential game** set in The Memory of
Stars universe. Nothing here is committed direction yet — it's a place to capture ideas
so they aren't lost, and to keep them consistent with the [series bible](../series-bible/).

## Suggested starting docs (add as the idea firms up)

- `concept.md` — the pitch: genre, platform, core fantasy, why this universe.
- `pillars.md` — 3–5 design pillars everything answers to.
- `mechanics.md` — how "the memory of stars" becomes a mechanic.
- `narrative.md` — where in the [timeline](../series-bible/timeline.md) the game sits and how it relates to the novellas.

> Keep game canon reconciled with the novellas — the [series bible](../series-bible/) is
> the shared source of truth for both.
