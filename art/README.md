# Art

Visual assets for The Memory of Stars.

| Folder / file | Contents |
|---------------|----------|
| [`art-style.md`](art-style.md) | The shared visual style guide (also used by image generation). |
| [`covers/`](covers/) | Novella cover art — name files `book-NN.ext`. |
| [`maps/`](maps/) | Maps of worlds, regions, and star charts. |
| [`concept-art/`](concept-art/) | Characters, ships, locations, key imagery. |

## Conventions

- Keep the **highest-resolution master** here; export web-sized copies into
  [`../docs/assets/images/`](../docs/assets/images/) for the site.
- Prefer descriptive, kebab-case filenames (`the-ashen-reach-map.png`).
