## Premise

A teenager enters an ancient intelligence as part of a mandatory rite of passage. It lets
each pilgrim experience carefully selected memories from generations of the dead. During
the ritual, the protagonist encounters a memory that the Archive insists does not exist.

This is the emotional entry point into the universe — memory as an intimate experience
before we explore it as infrastructure or power.
