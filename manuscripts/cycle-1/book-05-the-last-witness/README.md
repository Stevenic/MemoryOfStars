## Premise

Explorers discover an ancient intelligence containing the final memories of a nonhuman
civilization. It offers humanity its knowledge, but only if humans agree to become
carriers for the minds stored inside it.

This is the cycle's first large cosmological expansion. It confirms that humanity is
neither first nor alone — without explaining the deepest history of the galaxy.
