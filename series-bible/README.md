# Series Bible

The **canonical reference** for Memory of Stars. If a manuscript contradicts the bible,
one of them is wrong — reconcile them before moving on.

## Start here — the constitution

Two documents sit above everything else. Every story is measured against them.

1. **[foundation.md](foundation.md)** — what the universe _is_: vision, core question, tone, themes, the Writing Commandments.
2. **[seven-laws.md](seven-laws.md)** — the constraints stories must obey, what is intentionally left undefined, and The Writer's Test.

> **The core question:** _What must a civilization remember if it hopes to survive?_
> **The organizing metaphor:** _Civilization is a conversation across generations._

## Conventions

- **The constitution wins.** foundation.md and seven-laws.md outrank every other file here.
- **One entity per file.** A recurring character/location/faction gets its own file.
- **Don't answer the undefined early.** See the intentionally-undefined list in [seven-laws.md](seven-laws.md); when a story _does_ answer one, log it in [canon-and-continuity.md](canon-and-continuity.md).
- **Link, don't duplicate.** Reference other entries rather than restating them.
