# Atlas & Registry

The single source of truth for **where** things happen and **what** is out there — every
system, world, station, ship, megastructure, and significant object that has appeared in a
book (or is committed to appear by an outline). Companion to [`timeline.md`](timeline.md)
(**when**) and the [`locations/`](locations/) folder (one file per *recurring* entity;
this file is the index and the census).

> **Why this exists:** the universe should feel large and expansive. That feeling comes
> from knowing exactly how small the on-page footprint is — a handful of lit rooms in an
> enormous dark house. This file keeps the count honest, so every new book *chooses*
> whether to light a new room or return to a lit one.

## The canvas (author-set rules)

- **One galaxy.** All of *Memory of Stars* takes place in a single galaxy — ours-scaled,
  Star Wars-style: the setting is "the galaxy," no intergalactic travel, and other
  galaxies are never part of the story canvas. (Foundation already speaks this way: *"The
  galaxy is not ending. It is forgetting."*)
- **Thousands of settled systems** (foundation) — some colonies decades old, some
  hundreds of thousands of years old. The series will only ever visit a sliver; the
  sliver implies the rest.
- **Deep time.** Humanity is not the first great civilization here (Book 05's canon
  event — signed off 2026-08). The oldest infrastructure predates every culture that uses it.
- **Distance is real (Law 1).** Nothing in this file is "nearby." Every line between two
  entries below was paid for.

## Dating — the CR frame (proposed)

In-world cultures keep **local calendars** (Law 1: isolation breeds diversity — a single
universal calendar would flatten it). For *authoring*, the series uses a neutral
coordinate: **CR (Cycle Reference)**, with **CR 0 = the Pilgrimage of Lyra Ash**
(Book 01's main events). CR never appears on the page; it exists so synopses and this
atlas can agree. *(Proposed — confirm or replace; `timeline.md` carries the placements.)*

## Upkeep

- When a book is drafted, update this file **in the same pass as its canon-ledger**:
  new places/ships/structures land here first; recurring ones graduate to their own file
  in [`locations/`](locations/) (via `canonize`).
- Counts in this file are **on-page counts**. The galaxy stays huge by implication —
  never inflate the census to make it feel big; the smallness of the lit portion *is*
  the bigness.
