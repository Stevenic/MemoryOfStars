# Locations

One file per significant world, city, ship, station, or landmark. Copy
[`_template.md`](_template.md) for each new entry; name the file in kebab-case,
e.g. `the-ashen-reach.md`.

> The census of everything that has appeared — including one-off places and unnamed
> things — lives in [`../atlas.md`](../atlas.md). Entities graduate from the atlas to
> their own file here once they recur.
