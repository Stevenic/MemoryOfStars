# Writing Guide

How The Memory of Stars is written, so 30 novellas read like one series. Where the
[series bible](../series-bible/) governs _what_ is true, this guide governs _how_ it's
told.

## Contents

| File | Purpose |
|------|---------|
| [`commandments.md`](commandments.md) | **The Writer's Card** — core question, metaphor, Ten Commandments, Seven Laws, and Writer's Test on one page. Start here. |
| [`voice.md`](voice.md) | **The Voice** — the concrete, example-driven spec of how the prose sounds (derived from *The First Pilgrim*). |
| [`structure.md`](structure.md) | **The Shape Rule** — the length is the law (~28–34k, one-sitting chapters); the chapter grid is chosen per book. |
| [`style-guide.md`](style-guide.md) | Prose mechanics — the decisions of record: POV, tense, formatting, numbers, spelling, plus the banned-filler/adjective/adverb/music/image/dialogue rules digest. |
| [`voice-and-craft.md`](voice-and-craft.md) | Broader craft: rendering memory (the central force), craft touchstones, the undefined (see [`voice.md`](voice.md) for the sound of the prose). |
| [`revision.md`](revision.md) | **The pass system** — seven ordered revision passes ending in the blind A/B scoring gate; how a draft becomes a book. |
| [`naming-conventions.md`](naming-conventions.md) | How names of people, places, and coined terms are formed. |
| [`lexicon.md`](lexicon.md) | **The Lexicon** — the series' invented English (craft-level coinages, not in-world terms). Human-approval gated: a drafter proposes, never deploys. |
| [`craft-tchaikovsky.md`](craft-tchaikovsky.md) | **Craft notes from Adrian Tchaikovsky** — world-first process, the left wall, the one big lie, fight scenes, the knowledge triangle; with a mapping to this project's practice. |
| [`templates/`](templates/) | Reusable scaffolds for outlines, chapters, and character sheets. |

> **Canon lives in the bible.** This guide governs _how_ the series is written; the
> [foundation](../series-bible/foundation.md) and [Seven Laws](../series-bible/seven-laws.md)
> govern _what is true_. When drafting, keep the [Writer's Card](commandments.md) in view.
