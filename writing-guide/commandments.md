# The Writer's Card

Everything a Memory of Stars writer should be able to recite from memory. This is a
**quick reference** — the canonical sources are [`foundation.md`](../series-bible/foundation.md)
and [`seven-laws.md`](../series-bible/seven-laws.md) in the series bible.

## The core question

> **What must a civilization remember if it hopes to survive?**

## The organizing metaphor

> **Civilization is a conversation across generations.**

## The Ten Writing Commandments

1. Every technology changes culture.
2. Every civilization tells myths about itself.
3. Every myth contains some truth.
4. Every victory carries a permanent cost.
5. Wonder is more important than spectacle.
6. Questions are more memorable than answers.
7. Characters matter more than ideas.
8. The universe never revolves around one person.
9. History is discovered, not explained.
10. Memory is humanity's greatest technology.

## The Seven Laws (constraints — [full text](../series-bible/seven-laws.md))

1. **Distance Is Real** — travel is possible, never free.
2. **Memory Outlives Flesh** — everything leaves memories; the question is who can still read them.
3. **Intelligence Is Not Life** — consciousness takes many forms; none is superior.
4. **Technology Changes Culture** — every important invention reshapes society, or it isn't important.
5. **Every Civilization Forgets Something** — memory is always incomplete; truth is recoverable, never obvious.
6. **There Are No Chosen Ones** — history comes from choices, not destiny.
7. **Wonder Comes First** — every story earns one "Wow."

## The Writer's Test (the acceptance gate)

Before a novella is accepted:

- [ ] Teaches one new truth about the universe.
- [ ] Leaves one important mystery unsolved.
- [ ] Permanently changes at least one character.
- [ ] Changes civilization itself, even a little.
- [ ] Makes the universe feel larger at the end than at the start.

If not — rewrite it.
